# King Air 350 Systems Trainer Prototype v0.3

Offline HTML prototype for interactive system learning.

## Run
Open `index.html` in a browser. No server, build process or internet connection is required.

## GitHub Pages
Upload all files to a repository. Rename/copy `kingair350_systems_trainer.html` as `index.html` (already included in the ZIP), then enable GitHub Pages from the repository root.

## Scope
- Electrical schematic with selectable battery, left/right generators, external power, GEN TIES and BUS SENSE TEST.
- Fuel schematic with standby pumps and crossfeed state.
- Pneumatic/bleed schematic with left/right bleed valves.
- Responsive layout for desktop and mobile.
- Offline capable because all CSS and JavaScript are embedded.

## Important
This is a training prototype, not an approved flight operations tool. Always use current approved AFM/POH/QRH material for operational decisions.
