# King Air 350 Memory Trainer

Offline-PWA für GitHub Pages.

## Installation
1. Alle Dateien in den Root eines GitHub-Repositories hochladen.
2. Settings > Pages > Deploy from a branch > main > / (root).
3. Pages-Adresse in Safari öffnen.
4. Teilen > Zum Home-Bildschirm.
5. Einmal online starten, danach offline nutzbar.

Nur zu Trainingszwecken. Für operative Entscheidungen gilt ausschließlich das freigegebene aktuelle QRH.
